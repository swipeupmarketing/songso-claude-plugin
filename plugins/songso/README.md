# song.so plugin

Plan, launch and optimize Meta (Instagram/Facebook) ad campaigns for music releases and generate creative ad videos, with the song.so MCP connector and two skills bundled in one install.

## What is inside

- **Connector: song.so** (`https://mcp.song.so/mcp`). Add or connect it on the plugin's Connectors tab and sign in with your song.so account. It exposes smartlink, analytics, Meta ads, release/tour campaign and creative generation tools.
- **Skill: meta-music-ads.** Campaign structure, benchmarks, kill/keep decisions and the optimization workflow for music ads.
- **Skill: edit-generation.** The creative pipeline: Spotify preview to finished ad video, text hooks, lyrics, effects, cinematic scenes and bulk batches.

Both skills are thin loaders. They fetch the current playbook from the connector at the start of a session, so workflow and tool changes reach you without updating this plugin. The plugin itself only changes when its structure or trigger descriptions change.

## Setup

1. Install the plugin and connect **song.so** on its Connectors tab.
2. Ask for a release campaign, an optimization check, or a creative batch. The skills activate on their own.
